# Technical Assignment — N5Deal Marketplace Prototype

## Context

N5Deal is a marketplace focused on M&A opportunities and financial assets.

As the first stage of our technical selection process, we would like you to build a small working marketplace prototype.

The goal of this assignment is not to build a production-ready system. We want to understand how you approach a product problem, structure a small full-stack application, use modern AI development tools, make technical decisions, and deliver a usable result within a limited amount of time.

The task is intentionally not fully specified. Use reasonable assumptions and make your own product and engineering decisions.

**Expected effort:** no more than 24 hours from the start of the assignment to the final submission.

## Product Scenario

The marketplace has three roles:

- Buyer
- Seller
- Platform Manager

### Seller

A Seller can:

- publish an asset;
- browse Buyers;
- filter/search Buyers;
- contact a Buyer.

### Buyer

A Buyer can:

- create and maintain their profile;
- describe their investment/acquisition interests;
- browse available assets;
- filter/search assets;
- contact a Seller.

### Platform Manager

A Platform Manager can:

- see Buyers, Sellers, and Assets;
- search/filter marketplace participants and assets;
- remove or suspend participants that do not comply with platform requirements.

You can use the existing N5Deal marketplace as a product and visual reference: https://n5deal.com/all-listing

You do not need to reproduce it 1:1.

## Technical Requirements

- Next.js + TypeScript
- The result should be a working application, not only static screens
- Application state should persist after refresh
- Include enough demo data to evaluate the main flows
- Using AI development tools is encouraged

The rest — architecture, data model, UX, authentication approach, libraries, infrastructure, and implementation details — is up to you.

## Huge Plus

- High-quality Product User Flow with thoughtful UX decisions
- Architecture description with reasoning behind key decisions
- Visual consistency with N5Deal
- Well-designed persistent data model

## Plus

- AI Suggestions / Smart Filtering / Smart Validation or other relevant AI functionality
- Automated testing
- Thoughtful handling of edge cases not explicitly described in the assignment
- Multi-language support

## Deliverables

Please provide:

- Source code
- README with launch instructions
- Deployed version, if possible

In the README, briefly describe:

- key technical decisions;
- assumptions you made;
- AI tools you used;
- what you would improve with more time.

## What We Evaluate

We are interested not only in whether the application works, but also in:

- how you interpret a relatively broad product requirement;
- what you choose to prioritize;
- engineering quality;
- product and UX thinking;
- quality of technical decisions;
- ability to use AI tools effectively without losing ownership of the solution.

We do not expect every possible feature or edge case to be implemented. We are interested in the quality of the decisions you make within the scope you choose.
